# Practicas Unidad 3

Repositorio de Practicas realizadas en clase de lenguajes de interfaz en assembly con Irving32

## Indice de practicas

- Practica 1 Procedimiento — [Main.asm](<Practica 1 Procedimiento/Main.asm>): Muestra mensajes en pantalla y llama dos veces al procedimiento `mostrarAviso`. Tambien muestra las direcciones de las etiquetas donde se realizan las llamadas.
- Practica 2 Cadena — [main.asm](<Practica 2 Cadena/main.asm>): Solicita el nombre del usuario, lo guarda en un buffer y lo muestra. Al final, presenta la cantidad de caracteres escritos.
- Practica 3 Comparacion — [main.asm](<Practica 3 Comparacion/main.asm>): Define mensajes para entradas validas e invalidas y muestra el mensaje de entrada invalida. Incluye una etiqueta que compara ECX con cero.
- Practica 4 Manejo de Pila Manual — [main.asm](<Practica 4 Manejo de Pila Manual/main.asm>): Coloca dos numeros en la pila y llama a `MultiplicacionPila`. El procedimiento los multiplica y conserva el valor original de EBX.
- Practica 5 Macros — [main.asm](<Practica 5 Macros/main.asm>): Define el macro `MostrarMensaje` para imprimir texto y cambiar de linea. Lo utiliza para mostrar dos mensajes en pantalla.
